# SK 세븐모바일 (SK텔링크) — 길 지도

수집 갈래가 2026-09-01 뚫음. SKT 자회사 알뜰폰. **공식 다이렉트몰: https://www.sk7mobile.com**
(도메인 확인 근거: `<title>SK 7mobile`, 상세 유의사항 안에 「SK텔링크 다이렉트몰 (www.sk7mobile.com)」이
회사가 직접 지정하는 가입채널로 적혀 있다. 사업자번호 `wrkr_no=1048143391`.)

## 통로 (세션·쿠키·JS 없이 정적 HTML로 다 나온다)

1. **목록 — 유심/eSIM 50개**
   `GET /prod/data/callingPlanList.do?refCode=USIM&searchCallPlanType=PROD_USIM_TYPE_ALL&searchOrderby=6`
2. **목록 — 휴대폰 13개**
   `GET /prod/data/callingPlanList.do?refCode=PHONE&searchCallPlanType=PROD_LTE_TYPE_ALL&searchOrderby=6`
3. **상세** `GET /prod/data/callingPlanView.do?refCode=<USIM|PHONE>&prodCd=<코드>`
   - 코드는 목록의 `onclick="fnSearchView('PD00000296');"`에서 꺼낸다.
   - 목록 폼은 원래 POST 서브밋이지만 **GET 쿼리로도 그대로 먹는다.**

받아오는 스크립트: `scripts/fetch-seven-plans.mjs <출력폴더>` (목록 2장 + 상세 63장을 그대로 저장)

## 값이 어디 있나

| 값 | 어디서 |
|---|---|
| 세대(LTE/5G) | 상세 본문 첫 줄 배지 |
| 이름 | 배지(`LTE`·`5G`·`추천`·`프로모션 할인`) 다음 첫 줄 |
| 데이터·음성·문자 | 상세의 `데이터 제공량` / `음성 제공량` / `문자 제공량` **바로 다음 줄** |
| 정가 | `기본료` 바로 다음 줄 |
| 판매가 | `프로모션 할인 후 기본료` 또는 `약정 할인 후 기본료` 바로 다음 줄 |
| 속도제어 | **목록 카드의 배지**(유심 `badge-keyin`, 휴대폰 `badge5-bg`)가 제일 확실하다 |

## ⚠️ 함정

- **상세 본문의 인라인 SVG가 어마어마하게 길다.** 카드 하나를 정규식으로 자를 때
  `.{0,2500}?</a>` 같은 상한을 두면 **카드의 절반이 안 잡힌다.** SVG를 먼저 지우고 자른다.
- 배지 툴팁(`data-tooltip="…최대 1Mbps…"`)에도 속도가 적혀 있다. **툴팁을 먼저 지워야**
  옆 요금제의 속도를 잘못 가져오지 않는다.
- 요금 필드가 두세 개다. **어느 것이 월정액인지는 목록이 말하지 않는다 — 상세 유의사항으로만 판정한다.**
- 유심 탭과 휴대폰 탭의 요금제 코드는 **하나도 겹치지 않는다.** 둘 다 받아야 전수다.
- 휴대폰 탭에서 `searchCallPlanType`을 카테고리 코드로 바꿔 불러도 **결과가 안 바뀐다**(늘 같은 13개).
  아코디언은 이미 다 그려져 있고 JS가 접기만 한다.

## 특가 판정 — 실측 (63개 전부 확인)

| 유형 | 개수 | 원문 문구 | 어떻게 담았나 |

| 평생 할인 | 55 | 「유심요금제 프로모션 할인 혜택은 **해지 전까지 평생 적용**되며, 가입 첫달은 일할 할인 계산됩니다.」 | `monthlyFee` = 할인 후 기본료, `promo` null, memo에 정가 |
| 기간 있는 특가 | 2 | 「**12개월간 3,300원, 13개월차부터 4,400원 청구**」 | `monthlyFee` = 4,400, `promo` = {months:12, feeDuring:3300} |

| 할인 표시 없음 | 1 | — | 기본료 그대로 |

## 뒤진 곳 (못 찾은 것 포함)

- `/main.do`가 진짜 첫 화면이다. `/`는 `<meta http-equiv="refresh">`로 여기로 던진다(본문 6KB).
- 요금제 목록 링크는 첫 화면 GNB의 `상품서비스`(USIM)와 `휴대폰 > 휴대폰 요금제`(PHONE) 두 군데뿐.
- 내부 JSON API는 **없다.** 챗봇(`/chat/init/create/token.do`)·배너 말고는 ajax가 안 보인다.
- 약정 기간을 적어 둔 곳을 「약정 할인」 5개의 상세·FAQ에서 찾지 못했다.
  `선택약정할인제도`라는 링크 글자만 63장 전부에 있고 눌러도 요금제별 기간은 안 나온다.
