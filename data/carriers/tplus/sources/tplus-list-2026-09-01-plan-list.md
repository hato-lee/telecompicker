- 공식 사이트: https://www.tplusmobile.com (한국케이블텔레콤 / 태광그룹). 목록 화면 https://www.tplusmobile.com/main/rate/join
- 통로: `POST https://www.tplusmobile.com/BackBone/rate/rate_list` — HTML 조각을 준다.
  응답은 `ㅹㆄ` 로 나뉜다: `[TRUE, HTML, 총건수, 이번건수, tp, 다음키, 누적]`. 12쪽, **총 235개**.
- 세대(LTE/5G)는 `sel_network=LTE|5G`로 따로 불러 갈랐다 → LTE 209 / 5G 26 (합 235, 딱 맞음).
- 상세: `GET /main/rate/plan_details?seq=<seq>` — 서버 렌더 HTML. seq는 재조회해도 같은 값이었다(고정).
- **덮어쓰지 않는다.**

## 값이 어디에 있나 (카드 HTML)

| 뜻 | 자리 |
|---|---|
| 망 | `<i class="badge skt / kt / lgu">SKT / KT / LGU+</i>` |
| 할인 종류 | `<i class="badge custom">7개월 요금할인 / 평생 요금할인 / 복지요금제 / 시니어 요금제(만65세 이상) / 외국인 전용 요금제 / 스마트기기 전용 / 5G 요금제</i>` |
| 데이터 | `<p class="desc desc20px700">` — 「100GB 최대 5Mbps」 「11GB 일 2GB 최대 3Mbps」 |
| 통화·문자 | `<span class="ico call">` / `<span class="ico message">` / `<span class="ico video">` |
| 특가 끝난 뒤 값 | `<p class="desc throthDesc">` (⚠️ 「평생 요금할인」 요금제에서는 이 자리가 **정가**다) |
| 지금 내는 값 | `<div class="amountArea">` 안 `.textPoint` |
| 한 줄 설명 | `<span class="text">7개월간 월 11,900원, 7개월 후 월 48,400원</span>` |

## ⚠️ 값은 카드가 아니라 **상세**로 읽었다

상세 `<div class="amountArea">`가 세 값을 또렷이 나눈다:

| 자리 | 뜻 |
|---|---|
| `.desc16px700b50` | 「7개월 후 월 48,400원」 / 「평생 월 25,900원」 / 「복지할인 대상자만 가입 가능」 |
| `.throthDescMedium` | 정가 (없을 수도) |
| `.desc28px700` | 지금 내는 값 |

카드의 `throthDesc`만 믿으면 「평생 요금할인」 요금제에서 정가를 특가 후 값으로 잘못 읽는다.
(예: 5G 티플온 150GB＋_평생 할인 — 카드 throthDesc 59,400원은 **정가**이고, 실제 월 요금은 25,900원)

1. 정보이용료(소액결제 등)은 데이터 요금과 별도로 부과됩니다.
2. 프로모션 요금제 할인기간 적용은 3개망 동일하게 일할 계산됩니다.
3. **기존 티플러스 고객은 요금제 변경시 프로모션 혜택 적용이 불가합니다.**
4. 중도가입/해지시 기본량과 청구 금액은 일할 계산되어 적용됩니다.
5. 중도해지시 데이터 무제한 요금제의 경우 일할 계산된 기본 제공량을 초과했을 경우 초과분만큼 추가 과금됩니다.
6. 모든 음성/문자/데이터 제공량은 국내 통화에 한합니다.

## ⚠️ 부가세 — 원문이 말하지 않는다

**티플러스 사이트 어디에도 「부가세 포함」이라는 문구가 없다.** (요금제 목록·상세·FAQ 모두 뒤졌다.)
정가가 1.1의 배수(52,800 = 48,000×1.1, 39,600 = 36,000×1.1, 22,000 = 20,000×1.1)라 부가세 포함 표시가로 보이지만
**원문이 밝히지 않으므로 지어내지 않았다.** 표시가를 그대로 담고 memo에 이 사실을 적었다.

## ⚠️ 세대(5G/LTE)가 원문 안에서 어긋나는 6개

`5G 통화안심 6GB / 10GB / 15GB / 20GB / 25GB / 30GB` (전부 SKT망):

- 요금제 **이름**이 「5G」로 시작하고, 카드 **배지**도 「5G 요금제」다.
- 그런데 상세의 **「통신유형」 항목은 LTE**이고, 목록의 `sel_network=LTE` 필터에도 이 6개가 들어 있다.

구조화된 항목(통신유형 + 필터) 두 곳이 LTE라 **LTE로 담고 memo에 충돌을 적었다.** 총괄 확인이 필요하다.
