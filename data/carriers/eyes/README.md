## 통로 — 따로 없다. **HTML 그대로가 통로다**

`GET /payplan/all_plan/?&page=N` (1..12) 을 그냥 받으면 카드 20개가 **서버 렌더된 HTML**로 온다.
쿠키·헤더 필요 없음. 카드 0개가 나오는 쪽(13쪽)이 끝이다.

- `POST /payplan/plan_filter_cnt` 는 **개수만** 준다(목록 아님). 목록 ajax는 없다.
- 로더: `/assets/js/eyes3.6/views/plan3.6.js` — 페이지 이동은 `#page` hidden input + `?page=` 링크.
- 긁는 스크립트: `scripts/fetch-eyes-plans.mjs`

## 값 필드 — ⚠️ 함정

카드 하나는 `<a href="/payplan/plan_info/…" class="plan_card full">` 로 시작한다.

| 어디 | 뜻 |
|---|---|
| `<span class="badge skt|kt|lg">` | 망 (`SKT` / `KT` / `LGU+`) |
| `<span class="badge collab">` | 제휴 브랜드(올리브영·다이소·CU 등) 또는 **`복지요금제`** |
| `<span class="badge period">` | `7개월 할인` / `12개월 할인` / `24개월 할인` / **`평생할인`** |
| `<p class="h2 plan_tit">` 안의 span들 | 데이터. `["100GB","5Mbps"]`, **`["11GB","2GB/일","3Mbps"]`** |
| `.plan_info` 안 `<p>` 2개 | [0]=통화, [1]=문자. 「기본제공 + 영상/부가통화 300분」이면 무제한 |
| `.org_p` | 정가(취소선) |
| `.period` + `.current_p` | 「첫 7개월간」 + 「월 10,900원」 |
| ⭐ `<button class="tooltip_btn" data-discount='…'>` | **할인 판정의 열쇠.** 아래 참조 |

### ⭐ `data-discount` — 이것만 보면 특가 판정이 끝난다

세 가지 모양뿐이다(236개 전수 확인):

1. `[{"label":"7개월 동안","price":10900},{"label":"평생","price":55000}]` (108개 — 7개월 69·12개월 16·24개월 14·18개월 4·10개월 2·6개월 2·9개월 1)
   → **promo{months:7, feeDuring:10900}, monthlyFee=55000.** 달수는 6·7·9·10·12·18·24가 관측됨.
2. `[{"label":"평생","price":6900}]` (57개) — 카드 배지도 `평생할인`
   → **기간 없는 평생 할인. monthlyFee=6900**(정가 33,000원은 memo로).
3. 없음 (71개, `.org_p` 도 비어 있다) → **표시가가 곧 제값.**

상세 페이지 「요금할인 정보」 표가 이 값을 그대로 다시 보여 준다(눈으로 4건 대조 완료:
10650 / 10641 / 605 / 30).

### ⚠️ 세대(5G·LTE)를 사이트가 말하지 않는다

- 목록 필터에 통신사·데이터·속도·음성·가격·할인기간·복지는 있어도 **5G/LTE 칸이 없다.**
- 상세 페이지·이용안내·유의사항 어디에도 「LTE」「5G」라는 글자가 없다
  (요금제 이름 안에 들어간 경우만 예외).
- 가입 버튼 인자 `openFaceAuthNotiModal(seq, prod_cd, name, telco, payplan_gb, agent)` 의
  `payplan_gb` 는 **관측 전부 `'C01'`** — 세대가 아니라 카테고리다.
- 요금제 코드에 규칙성은 보인다(LGU+ 5G=`LPZ00…`, LGU+ LTE=`LPZ10…`)지만
  **원문이 그렇게 말한 적이 없어 근거로 쓰지 않았다.**

→ 그래서 **이름이 「5G 」로 시작하는 것만 `5G`**, 나머지는 `LTE`로 담고
**요금제마다 memo에 「원문이 LTE라고 직접 말한 것은 아니다」를 남겼다.** 총괄 판정 필요.

## 담지 않은 것 (236 → 205)

| 왜 | 몇 개 |
|---|---|
| 일 단위 데이터 (`11GB + 2GB/일`, `5GB/일`) — DECIDED | 25 |
| 복지 요금제 (`badge collab` = `복지요금제`) — 가입 자격 제한 | 3 |
| 태블릿·스마트기기용 (`세이브머니유심(태블릿/스마트기기 …)`) | 2 |
| 외국인 전용 (`[L]foreigner(…)`, 혜택줄 「(외국인Only) : 내국인 가입불가」) | 1 |

- ⚠️ `[L]아이즈특판11GB+일2GB`(10639)는 **데이터 칸엔 「11GB+3Mbps」만 적혀 있고 이름에만 「일2GB」가 있다.**
  이름을 믿고 일 단위로 보아 뺐다.
- `아이즈우정(100분/3G)`·`아이즈포스트(500분/5G)` 의 `3G`·`5G` 는 **3GB·5GB 라는 뜻**이다(데이터 칸이 그렇게 적혀 있다).
  3G 망 요금제가 아니다.
- 청소년·시니어·키즈 전용은 **한 개도 없었다**(이름·혜택줄 전수 검색).

## 뒤진 곳 (헛수고 기록)

- `/payplan/explan`(알뜰폰 설명), `/payplan/usim` — 세대 정보 없음.
- 상세 HTML에 `LTE`·`5G` 문자열 검색 — 요금제 이름 말고는 안 나옴.
- 알뜰폰허브(mvnohub.kr) 상세 URL — 302로 튕김. 세대 대조에 못 썼다.
- **부가세**: 정가가 11,770원(=10,700×1.1)·25,300원(=23,000×1.1)·33,000원(=30,000×1.1) 처럼
  1.1 배수인 것이 많아 부가세 포함으로 **보이지만**, 원문이 그렇게 적은 곳을 못 찾았다.
  화면 표시가를 그대로 담고 memo에 적었다.
