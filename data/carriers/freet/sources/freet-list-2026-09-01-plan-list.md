```
{{if ~root.isViewBasic && (foreverDiscAmt + periodDiscAmt) > 0 }}
  <del>월 {{:~formatNum(basicFee)}}원</del>
{{/if}}
<p class="price">월 <strong>{{:~formatNum(monthlyFee)}}</strong>원</p>
{{if periodDiscMonth && periodDiscMonth != '0'}}
<p class="spec">{{:periodDiscMonth}}개월 후 {{:~formatNum(basicFee-foreverDiscAmt)}}원</p>
{{/if}}
```

상세 페이지 배지(`plan/ratePlan/detail`) 원문:

```
{{if periodDiscMonth > 0}}<span class="tag-type4 c3">{{:periodDiscMonth}}개월 할인</span>{{/if}}
{{if (foreverDiscAmt != null && foreverDiscAmt > 0) && (periodDiscAmt == 0 || periodDiscAmt == null)}}
  <span class="tag-type4 c3">평생 할인</span>{{/if}}
```

→ `periodDiscMonth = 0` 이고 `foreverDiscAmt > 0` 이면 **원문 스스로 「평생 할인」**이라 부른다.
195개 전부에서 `monthlyFee = basicFee − (periodDiscMonth ? periodDiscAmt : foreverDiscAmt)` 가 맞았다(불일치 0건).
