# 이미 결정된 것 — 갈래는 이 문서를 **맨 먼저** 읽는다

**갈래(따로 도는 일꾼)가 원문을 열면 「우리에게 없는 줄」이 계속 나온다.
그중 일부는 빠뜨린 게 아니라 하토님이 「안 넣는다」고 정하신 것이다.**

> **철칙: 이 문서에 있는 줄은 원문에 있어도 넣지 않는다.**
> 정말 넣어야 한다고 생각하면 **직접 고치지 말고** 보고서에 「⚠️ 결정 재검토 제안」으로 적는다.
> 결정을 뒤집는 것은 하토님만 하신다.

(카드피커에서 검증된 규약이다. 2026-08-28에 갈래가 하토님 결정을 모른 채
뺀 값을 되살렸고, 그 허수가 추천 1등을 두 번 만들었다.)

## 2026-09-01 — 총괄이 「안전한 쪽(적게 세는 쪽)」으로 정한 것 (하토님께 보고 예정)

카드피커 ㉯ 선례: 원문이 애매한 자리는 총괄이 안전한 쪽으로 정하고 목록으로 보고한다.

| 무엇 | 결정 | 왜 |
|---|---|---|
| **가입 대상이 제한된 요금제** (청년·시니어·청소년 등 연령 전용, 외국인 비자 전용 등) | 1차에서 **안 담는다** | 우리 질문 4개에 나이·자격이 없어서, 담으면 **가입 못 하는 사람에게 추천**할 수 있다(부풀리기). 나이 질문을 넣을지는 게이트 2 때 하토님께 여쭙는다. 선례: SKT Easy 4종(D·E 비자 외국인 전용, 2026-09-01) |
| **3사 선택약정 25% 할인** | 1차에서 `monthlyFee`는 **공시 정가**로 담는다. 할인 반영 방식은 열린 물음으로 | 원문(공시)이 말하는 값이 정가다. 할인가로 담으면 약정 안 하는 사람에게 부풀리기가 된다. 화면에서 어떻게 알릴지는 게이트 2 안건 |
| **일 단위 데이터 요금제** (「일 2GB」식) | 1차에서 **안 담는다** (스키마에 그릇 없음) | 월 GB로 환산하면 추정이 된다. 몇 개나 되는지 세어 보고 그릇을 만들지 정한다 |
| **5G/LTE 구분 없는 「통합」 요금제** | `generation`에 **`5G/LTE` 값을 신설**해 원문 그대로 담는다 | KT 현행 라인업 전체(38개)와 SKT 베스트·라이트(39개)가 원문에 「5G/LTE 구분 없이」다. 5G로 적으면 지어낸 값이 된다. 화면·계산 어디에도 세대 필터가 없어 안전한 확장 |
| **기간이 원문에 없는 프로모션 할인가** | `promo`에 **담지 않는다** — `memo`에만 남긴다 | LGU+ 내부 API가 너겟65→53,800원 등 할인가를 주지만 **몇 개월인지 원문 어디에도 없다.** `months`를 지어낼 수 없다. 정가로 계산하면 절약액이 적게 나올 뿐(안전한 쪽) |
| **LGU+ 데이터플랜 「일반」(원문 「만 35세~」)** | **담는다** | 35세 미만은 **같은 값**의 유쓰 변종으로 안내된다 — 누구에게 권해도 그 값에 가입할 수 있어 부풀리기가 아니다. LGU+ 스스로 「일반」·「전체」 탭으로 분류 |
| **알뜰폰 「프로모션 요금」(기간 없는 상시 판매가)** | 원문이 **「월정액은 실제 개통 시점의 판매가로 적용」류 문구로 판매가=월정액임을 밝히면** monthlyFee=판매가(프로모션 요금), promo는 null, memo에 정가와 그 문구 인용. 그런 문구가 없으면 기존대로 정가+memo | kt엠모바일 실측(2026-09-01, 초알뜰 1GB 상세 유의사항): 정가 15,400원·판매가 2,900원 — 아무도 정가를 내지 않는데 정가로 담으면 알뜰폰 비교가 무의미해진다. 「상시 변동 가능」 위험은 checkedAt 배지·재수집으로 진다 |

## 우산에서 물려받은 결정 (다시 논의하지 않는다)

- **3원칙**: 부풀리지 않는다 · 돈으로 말한다("1년에 얼마") · 증명한다(원문 링크 + 확인 날짜)
- 이름 "베네핏"은 **가제**. 사용자에게 보이는 곳엔 "통신비피커" 또는 "베네핏(가제)"
- 칸끼리는 **순수 링크만**. 데이터를 주고받지 않는다
- 검사는 **`npm run build`** (부분 확인도 `npx tsc -b`). vitest 통과만으로 「배포된다」고 말하지 않는다
- **하토님 게이트 3개**: ✅설계(2026-09-01) → ⬜화면 첫 모습 → ⬜개업(배포)
- **Sonnet 5 시험 운행**(하토님 승인 2026-08-28): 첫 수집 라운드에서 갈래 한둘을 sonnet으로
- 값싼 모델(haiku·sonnet)에게 판정을 시키지 않는다. 지시문에 「모르겠으면 "원문이 말하지 않는다"라고 적어라」
- 도메인 구매·이름 확정 논의는 보류
- 「값이 달라요」 신고 링크는 안 만든다 — 정확성은 원문 재수집으로 푼다 (카드피커 2026-08-23)

## 아직 안 정해진 것 — 갈래가 혼자 정하지 않는다
